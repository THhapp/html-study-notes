# 独立 HTML 演示的交付

适用于任务需要的独立 HTML 可视化。静态 SVG、Mermaid 或已有页面内的局部图解采用各自的交付方式，不套用完整 HTML 骨架。以下区分默认做法、可选工具与实际限制。

## 自包含与直接打开

独立演示默认交付可直接打开的一份 `.html`，包括字符编码、viewport、标题与语义结构。CSS、必要脚本、数据及 SVG/MathML 随文件保存，避免依赖在线资源或预览服务器。位图确有需要时可内嵌并控制体积。现有项目另有资源组织时，以任务约定为准。

默认浅色白底并声明适当的 `color-scheme`，使原生控件可读；具体主题以任务要求为准。小演示只组织所需图形和控件，无需套用完整示例页面。

可在开发时拆分样式、脚本与领域数据；最终阅读不应要求用户运行 Python 或构建命令。检查实际输出，不只检查源片段。

## 静态信息与交互增强

HTML 中保留理解当前图形所需的前提、标签、图例及必要结果。动态图按需要提供静态关键帧、数据或过程摘要，避免只剩“按按钮生成图”；这些内容针对当前演示，不是完整课程正文。

JavaScript 负责联动、参数计算与状态演示。动态数值也要说明初始条件；不能只将关键含义放在 tooltip、动画末帧或无解释的画布中。打印时保留适合纸面阅读的结果或关键过程，隐藏无作用的控件。

图解和主文共用例子时统一符号与数据。简单公式可使用原生 MathML 或清楚的文本；未经渲染的 LaTeX 不应成为最终唯一表达。需要第三方库时按实际版本、体积、许可和离线能力选择，不为简单图默认引入整套框架。

## 链接、状态与作用域

演示可以是主文的附件，允许按任务需要设置有用的返回或来源链接。链接与运行依赖分开考虑：点击后导航到主文不等于图形必须联网才能工作。静态图和主文之间的引用采用目标环境可维护的方式。

同页 ID 保持唯一，SVG marker、title、ARIA 引用使用适当实例前缀。复用时收窄 CSS 和事件作用域，避免污染宿主或其他图。对象身份稳定，模型与展示状态一致；切换或重置时清理旧播放与动效。

领域逻辑来自可信源码，材料和 JSON 作为数据处理，不执行其中的代码。内联 JSON 中的 `<` 应转义为 `\u003c`，避免 `</script>` 提前闭合。源码打包不能代替对不可信内容的消毒或核查。

独立本地演示默认不依赖持久化或后台进程。`file:` 下存储行为可能受限，可选保存失败时仍应能操作和读取。没有保存需求时直接使用内存状态。

## 可读性与操作

标签、单位、前提和结果要清楚，颜色以外有对应标识。按钮和输入保留语义、标签、可见焦点与适合的键盘操作。必要二维图可局部滚动，不把整图缩小到标签不可读。

过程控制按内容需要设置，不强制每张图都有播放、拖动和重置。默认让读者控制观察节奏，运行中的变化可暂停；减少动态效果时保留对应状态与等价操作。核查文字与图形对比度，不凭静态脚本通过宣称完整无障碍符合性。

## 现有工具的范围

`scripts/build_note.py` 和 `scripts/audit_note.py` 保留用于已有自包含 HTML 示例。其严格配置要求一个文档骨架、内联资源和纯篇内链接，并拒绝部分元素与脚本模式。它们不是所有可视化的通用校验器。

- 独立 SVG、Mermaid 不使用这套 HTML 检查。
- 合法的返回链接、已有页面中的组件或任务允许的依赖可能不满足该工具的约束；可直接实现并按实际目标核查。
- 静态检查不执行脚本，不证明领域算法、安全性、宿主兼容或全部无障碍要求。
- 打包器只组装可信片段，默认拒绝覆盖，检查标题、保留占位符和提前闭合片段；不消毒恶意 HTML。

修改脚本本身时验证相关行为；仅调整指令和说明时不重复整套组件回归。交付时据实区分浏览器、宿主实测和未验证项。
