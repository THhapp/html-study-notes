# 单 HTML 交付约定

这是本 skill 的默认交付要求，可由用户明确改变。它比 HTML 标准允许的范围更窄，目的是长期保存和直接阅读。

## 自包含与渐进增强

最终只有一份 `.html`，有 doctype、语言、字符编码、viewport、标题和语义正文。CSS、必要脚本、数据、SVG／MathML 全部内联；位图确有需要时使用内嵌 data 图片并控制体积。不附字体，不依赖 CDN、在线数学渲染、模块 import、fetch、iframe、其他本地文件或预览服务器。

默认页面和普通图表容器为纯白底色，固定浅色，声明 `color-scheme: light` 和相应 meta，使原生控件也保持浅色。不自动响应系统深色偏好，不增加主题切换器；用户明确提出其他主题需求时再调整。

核心定义、条件、结论与过程解释是原始 HTML 内容。JavaScript 负责增强已有内容，不负责首次下载或拼出整篇正文。不把关键知识只放在 tooltip、canvas、当前动画帧、点击后才生成的面板或 JSON 中。动态图附近提供静态数据表、过程表或结构说明，打印也能保留。

开发时可以拆分样式、脚本、正文并用打包器内联；这些是维护工具，不能要求读者运行 Python。打包完成后检查实际输出而不是仅检查源片段。

## 链接、数学与存储

默认导航仅用有效的 `#id`，同页 ID 全局唯一，SVG marker、title 和 ARIA ID 也如此。来源和相关主题以可读文字记录，URL 可写为普通文本，不设置跨文件／外站跳转。

简单公式可用原生 MathML 或语义清楚的文本。公式附近解释符号和条件；不用截图代替可选择的文字。未经渲染的 LaTeX 不应是唯一最终表达。确需内嵌数学库时，先核实版本、字体许可、体积和离线工作，保留所需声明；默认不打包第三方库。

阅读状态默认只保存在内存。`file:` 下 localStorage 行为没有统一保证，也可能被环境禁用；可选持久化须 try/catch 并保持无存储可用。不要把正确阅读依赖于浏览器存储、服务工作线程或后台进程。

## 页面与交互的硬边界

CSS 使用 `.hn-` 或专用组件前缀；领域脚本限制在所属图内。文本与数据用 textContent 等方式写入，避免将材料直接插成可执行 HTML。控制器不执行 JSON 中的代码，不使用 eval 或动态 Function。

控件用原生按钮和输入；说明、标签与可见焦点齐全。图不只靠颜色区别，键盘能完成等价操作。普通文本目标对比度 4.5:1；大字和图形另按适用标准判断，不凭肉眼宣称符合 WCAG。正文应在 320 CSS px 下重排，二维表格、关系图可提供明确局部滚动。按钮建议至少 32px 高，触屏可增至 44px；这是本包设计建议，不是对 WCAG 最小尺寸条款的完整复述。

禁止自动播放和无限循环。用户触发播放后可暂停、前后一步、重置；手动操作和页面隐藏停止旧播放。减少动态效果时移除位移／过渡，保留步骤与说明。

打印隐藏导航和操作工具，保留图题、静态数据、关键过程；补充 details 的内容应可打印。不要依赖背景色才能识别信息。生成打印 PDF 可用于验证，但不要求向读者交付第二份文件。

## 检查器能证明什么

`audit_note.py` 检查明确的资源引用、非篇内链接、重复 ID、缺失的篇内／ARIA 引用、常见网络与动态执行调用、文档骨架。它不执行脚本，不是安全沙箱，也无法穷尽混淆代码、CSS 解析、浏览器兼容性、知识正确性或所有无障碍要求。可信代码经静态检查后仍须真实浏览器阻断网络并操作验证。

`build_note.py` 只组装可信片段并校验输出。它会转义标题，拒绝能够提前终止 style/script 的源码和骨架占位冲突；不会消毒用户提供的恶意 HTML。处理不可信材料时先转成纯文字或经过适当消毒，再人工核查。
