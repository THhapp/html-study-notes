# 面向知识的图表模式

图解负责表达关系。正文仍给准确的一般知识，图前交代输入与约定，图后解释观察和边界。以下是选择菜单，不是每篇必须完成的清单。

| 知识关系 | 表达方式 | 合适的增强 | 必验的不变量／静态替代 |
| --- | --- | --- | --- |
| 分类、组成 | 带直接标签的分组／包含图 | 选择类别定位成员 | 集合归属准确；分组清单可读 |
| 一对多、多对多 | 节点—连线、矩阵或泳道 | 选中源同步目标／表格 | 方向、基数、重复含义；边表保留 |
| 同一对象多种表示 | 图、表、公式并排 | 稳定 key 联动选择 | 各表示实体相同；不把未选项隐去 |
| 数量比较 | 共基线条形图／点图 | 联动原始行、显示精确值 | 单位和零点清楚；原始数据可查 |
| 有序强度／差异 | 连续或发散色阶 | 参数切换、等值标记 | 中心点／范围有依据，颜色非唯一信息 |
| 操作前后 | 同尺度前后图＋变化标记 | 切换与局部转移 | 一次只变约定条件；静态对照可打印 |
| 算法推进 | 当前对象、队列／栈、步骤轨迹 | 单步、进度拖动、一次播放 | 帧由算法生成；完整过程表保留 |
| 拆分、合并、投影 | 保留身份的流向图 | 追踪来源与去向 | 守恒与合法中间态，去重前后区别 |
| 条件与反例 | 成立／不成立的最小对照 | 改一个参数观察边界 | 改动前提明确；解释一般判据 |
| 连续因果／函数 | 坐标曲线＋变量标记 | 原生 range 控制输入 | 定义域、极值、单位、离散化误差 |
| 时序与生命周期 | 时间线／状态机 | 当前事件高亮 | 时间／步骤不混用；转移条件清楚 |
| 机制的层次细节 | 总览＋局部放大／展开 | 可选详细计算 | 必要定义始终可见，不以折叠掩盖缺项 |

## 色彩先表达数据

类别用离散色；有序量用有序色阶；围绕有意义中心的偏差才用发散色。单系列数量图使用一个色调是合理的，不为了“丰富”给每条柱随机换色。丰富来自多个表示、局部强调、标注和恰当空间结构。

内容标签的蓝／琥珀／橙／红是一套语义，图中的对象身份和状态是另一套。类别颜色稳定，当前选择优先用外框、下划线、粗线或“当前”文字叠加；避免把对象本色不断改成状态色。默认弱化无关线，突出本步新增／影响对象；避免大面积高饱和底色。

直接标注通常比远处图例更易对应。仍需图例时，符号和字义应能脱离颜色阅读。小文字不使用未经对比度核验的图表线条色。

## 图形技术的选择

- DOM／CSS：队列、属性块、分组和可访问按钮；文字自然重排，适合少量对象。
- SVG：连线、坐标、结构和可选择标签；原生矢量可保存，不需要库。唯一 ID 要覆盖整页。保持标签实际尺寸，不把整图缩到字不可读。
- Canvas：大量数据或连续场才考虑；同时提供 DOM 控制与数据／结构说明。不能只放画布。
- 原生表格：严谨对照和离散值，使用 caption、行列标题；可与视觉图联动，而不是被视觉图取代。
- MathML：符号结构；记号必须在邻近正文解释，不把一串公式当作过程图。

窗口改变后，连线必须仍指向对应对象。固定拓扑可以统一 viewBox 坐标与百分比布局；DOM 自由排布则实测元素位置并在 resize／布局改变后重绘。不要在全页滚动坐标中混用局部位置。

## 动效的知识收益

有意义的位移可保留对象身份，有意义的高亮可指出本步差异。连续闪烁、计数器滚动、滚动揭幕和无解释的整图淡入不会自动增加理解。不要宣称交互或动画必然改善学习；复杂度和读者已有知识会影响效果。

默认静止；停留时间由读者控制。过程较短可直接并列全部状态；较长过程才用控制器，仍保留可扫读的过程摘要／表。范围拖动必须能抵达所有离散合法状态，不能将插值帧误说成领域合法状态。
